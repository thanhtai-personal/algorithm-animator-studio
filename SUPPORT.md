# Support

This project is currently preparing for an open-source release and **does not yet provide a stable version, a support SLA, or maintainer-on-call coverage**.

- Setup and local TTS engines: [README](README.md#voice-provider-setup) and [voice provider guide](docs/local-voice-services.md).
- API/render architecture: [Architecture](docs/oss/ARCHITECTURE.md).
- Tests and build failures: [Development guide](docs/oss/DEVELOPMENT.md).
- Third-party model permissions: [Third-party notices](THIRD_PARTY_NOTICES.md).
- Bugs/features: GitHub Issues once the repository is Public and issue tracking is enabled. Include OS, Node version, logs stripped of keys and steps to reproduce.
- Sensitive vulnerabilities: follow [SECURITY.md](SECURITY.md) instead of public issues.

The optional providers are maintained by their upstream projects. This repository cannot guarantee upstream models, packages, services or licenses remain available.
