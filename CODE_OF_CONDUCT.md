# Community code of conduct

Algorithm Animator Studio aims to be a respectful environment for people learning, teaching and building software across languages and experience levels.

## Expected behavior

Discuss technical ideas in good faith; offer actionable feedback and respect other contributors. Disagree about implementation choices without attacking people. Credit sources and avoid posting others' private data, recordings or credentials.

## Unacceptable behavior

Harassment, discriminatory remarks, threats, sexualized harassment, doxxing, deliberate intimidation, spam or repeated disruptive conduct are not acceptable in project spaces.

## Moderation and reports

Maintainers may remove content, close issues/PRs, limit participation or block accounts for serious or repeated violations. Please report incidents privately through the maintainer contact options described in [SECURITY.md](SECURITY.md); public security advisories are for vulnerabilities, not general conduct reports. Reports should include links/context and will be handled with attention to privacy. No guaranteed response window is advertised.

This policy covers issues, pull requests, discussions and other project-managed spaces. It does not override GitHub's platform policies.
