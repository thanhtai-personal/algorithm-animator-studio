# Tiến Độ Module Tasks

## Cách dùng
- Mỗi module có 1 file tiến độ riêng trong `progress/modules/<module>/tasks.md`.
- Sau khi hoàn thành coding task module, cập nhật checklist và append log vào đúng file module.
- Trong completion log bắt buộc có dòng `Token usage` (input/output/total hoặc total).
- Không dùng `master task` để theo dõi tiến độ; bắt buộc theo dõi bằng checklist trong file index module.
