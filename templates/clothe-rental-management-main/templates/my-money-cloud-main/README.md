# My Money Cloud

Repo chứa 2 app:
- `Next-cli/` Next.js App Router (chính)
- `Vite-cli/` Vite app (tham khảo)

## Quick start (Next.js)
1) Vào thư mục `Next-cli/`
2) Configure Supabase env vars (xem `Next-cli/SETUP.md`)
3) Cài dependencies và chạy dev cloud
```bash
cd Next-cli
npm install
npm run dev
```
